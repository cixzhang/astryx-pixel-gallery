Pixel UI — drawElementImage → WebGL shader pixelation

The DOM cluster (native 3× design, with photo avatar) is rasterised ONCE by drawElementImage into a capture canvas at full 480×360. Each panel below is a WebGL canvas texturing that capture and resampling it in a fragment shader onto a 160×120 pixel grid — the shader, not the browser's compositor, decides what a "pixel" is. Grid = 160×120, pixel unit = 3px.
